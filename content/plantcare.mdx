An iOS app that identifies plants from a photo, explains how to look after them and reminds you to water them. The interface is in Polish and English.

The app is built with Expo and React Native. It talks to a Hono API running on Cloudflare Workers: Better Auth with Sign in with Apple or Google, Neon Postgres through Hyperdrive with a Drizzle schema, and photos stored in R2. Plants are identified by a Gemini model through OpenRouter, with the prompt and the Zod schemas shared between the app and the API. The model and prompt were picked with a small evaluation tool kept in the repo.

Everything lives in one pnpm and Turborepo monorepo, and the infrastructure is code too (Alchemy). A push to `main` deploys the API and the website to the dev stage; a version tag deploys to production after a manual approval.

## Features
- Plant identification from a photo: common and Latin name, family and how sure the match is
- Care plan: watering, light, temperature and more
- Your plants list with watering reminders
- Sign in with Apple or Google
- Per-user rate limits and a shared cap on model calls to keep costs in check
