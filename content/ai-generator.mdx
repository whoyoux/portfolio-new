Type a prompt, get an image or a voice-over. Every generation costs a credit, and credits are bought through Stripe.

I built it to wire an AI API, file storage and payments into one Next.js app – and to learn self-hosting: it ran on my own VPS with Docker and Coolify.

## Features
- Text → image with built-in styles or a custom one
- Text → speech with a choice of voices
- Credits bought through Stripe Checkout and spent per generation
- Dashboard with every generated asset, stored on S3 through UploadThing
- Auth with Lucia, server actions validated with Zod
