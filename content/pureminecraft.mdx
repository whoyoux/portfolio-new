A paid whitelist for a private Minecraft server. Players sign in with Discord, buy a permanent spot, set their in-game name – and the server itself asks this app who is allowed in.

The part I like most is the whitelist endpoint: the Minecraft server calls it with the player's username and a secret header, gets a yes/no back, and the game's whitelist is never edited by hand.

## Features
- Sign in with Discord
- One-time purchase of server access through Stripe Checkout and a webhook
- In-game name verification, changeable once a day
- Whitelist API for the server, protected by a secret header and cached for 60 s
- Welcome and purchase emails through Resend (React email templates)
- Dashboard with access status, billing and server info
- Account deletion
